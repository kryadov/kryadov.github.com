# Modern IT modelling: standards and tools

Standards:

1. [TOGAF® Standard](https://www.opengroup.org/togaf): at its core is the Architecture Development Method, ADM. The method is described in detail, which is what sets TOGAF apart. It is meant for every kind of enterprise that develops, implements and applies an architectural approach.
2. [ArchiMate](https://en.wikipedia.org/wiki/ArchiMate): a language for describing the architecture of enterprise and engineering systems (enterprise architecture modelling). ArchiMate is meant for high-level modelling and analysis of the different areas of an enterprise and the relationships between them. It does not focus on implementation details and does not replace UML, BPMN or ERD; it complements them.
3. [GOST R 57100-2016](https://allgosts.ru/35/080/gost_r_57100-2016): the Russian national standard for systems and software engineering: architecture description.

Tools:

1. [Sparx Enterprise Architect](https://sparxsystems.com): a tool for building and visualising models, aimed at project teams as well as individual developers and analysts. Teams work on a project through replication, version control integration and file sharing over the network. Its features also include project documentation for code and databases, a project discussion forum and RTF report generation.
2. [QPR Enterprise Architect](https://www.qpr.com/products/qpr-enterprisearchitect): a solution for collaborative enterprise architecture modelling. There are single-user editions, and a process-modelling-only edition, Process Designer.
3. [SCADE Architect](http://www.esterel-technologies.com/products/scade-architect/): an integrated environment for designing and modelling complex systems. With SCADE Architect, systems engineers efficiently handle:

    - System design, functional decomposition and system architecture
    - Operational requirements and use case scenarios
    - Interface control documents (ICD) for the system and/or subsystems
    - Processes defined by the industry standards ARP 4754A and ISO 26262.
4. [PowerDesigner](https://www.sybase.ru/products/powerdesigner/): a design tool with a shared project repository that combines object-oriented, conceptual and physical modelling, Java and XML included, in a single integrated environment. PowerDesigner takes modelling to a new level by combining database design with powerful UML-based object modelling. A separate module designs and builds data warehouse models.
5. [Avolution Abacus](https://www.avolutionsoftware.com/discover-abacus-6-0/): models business architecture, including the process, application, data and technology layers. Abacus users can choose from more than 100 standard industry architecture frameworks and modelling notations, including TOGAF and ArchiMate (it is a certified tool), BPMN, BIAN, APQC, UML, the Balanced Scorecard and others.
6. [Visual Paradigm](https://www.visual-paradigm.com): enterprise-level modelling plus a UML tool supporting UML 2, SysML and the OMG's Business Process Model and Notation (BPMN). Besides modelling it offers reporting and code engineering, generation included, and round-trip reverse engineering for a range of programming languages.
7. [IBM Rational System Architect](https://www.ibm.com/support/knowledgecenter/en/SS6RBX/sa_family_welcome.html): visualises and analyses enterprise architecture and shares information about it, supporting the organisation's change and transformation.
