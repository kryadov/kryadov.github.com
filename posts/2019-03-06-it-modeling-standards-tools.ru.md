# Современное моделирование в ИТ: стандарты и инструменты

Стандарты:

1. [TOGAF® Standard](https://www.opengroup.org/togaf) - содержит в своем ядре метод разработки архитектуры — ADM. Метод детально описан, что является отличительной особенностью TOGAF. Методология предназначена для всех типов предприятий, разрабатывающих, реализующих и применяющих архитектурный подход.
2. [ArchiMate](https://en.wikipedia.org/wiki/ArchiMate) ([rus](http://sewiki.ru/ArchiMate)) - язык архитектурного описания корпоративных и инженерных систем (моделирования архитектуры предприятия). ArchiMate предназначен для высокоуровневого моделирования и анализа различных областей предприятия и взаимосвязей между ними. Он не фокусируется на деталях реализации и не заменяет UML, BPMN или ERD, а дополняет их.
3. [ГОСТ Р 57100-2016](https://allgosts.ru/35/080/gost_r_57100-2016) - системная и программная инженерия. Описание архитектуры.

Набор инструментов:

1. [SPARX Enterprise Architect](https://sparxsystems.com) - средство создания и визуализации моделей, ориентированное на проектные группы, а также на отдельных разработчиков и аналитиков. Работа по проекту внутри группы осуществлятся с помощью репликации, интеграции с системой контроля версий, а также совместного использования файлов внутри сети. В возможности версии входят также создание проектной документации для кода и баз данных, форум для обсуждения проекта и генерация отчетов в формате RTF.
2. [QPR Enterprise Architect](https://www.qpr.com/products/qpr-enterprisearchitect) - решение для группового моделирования архитектуры предприятия. Есть варианты на одного пользователя. Есть вариант - только для процессного моделирования - Proccess Designer.
3. [SCADE Architect](http://www.esterel-technologies.com/products/scade-architect/) - представляет собой интегрированную среду для проектирования сложных систем и их моделирования. С использованием SCADE Architect системные инженеры эффективно решают следующий задачи:

    -   Проектирование системы, функциональная декомпозиция и разработка архитектуры системы
    -   Поддержка разработки эксплуатационных требований, разработка сценариев использования
    -   Разработка описаний интерфейсов (ICD) системы и/или подсистем
    -   Поддержка процессов, заданных промышленными стандартами ARP 4754A, ISO26262.
4. [PowerDesigner](https://www.sybase.ru/products/powerdesigner/) - средство проектирования с поддержкой общего репозитория проекта, которое сочетает возможности объектно-ориентированного, концептуального и физического моделирования объектов, включая Java и XML, в единой интегрированной среде. PowerDesigner обеспечивает возможности моделирования на новом уровне, совмещая функциональность продукта для проектирования баз данных с мощными средствами объектного моделирования, основанными на языке UML. Отдельный модуль позволяет проектировать и создавать модели хранилищ данных.
5. [Avolution Abacus](https://www.avolutionsoftware.com/discover-abacus-6-0/) - позволяет моделировать бизнес-архитектуру, включая уровни процессов, приложений, данных и технологий. Пользователи ABACUS могут выбирать из более чем 100 стандартных отраслевых архитектурных структур и нотаций моделирования, включая TOGAF и ArchiMate (сертифицированный инструмент), BPMN, BIAN, APQC, UML, Balanced Scorecard и т. д.
6. [Visual Paradigm](https://www.visual-paradigm.com) - создание моделей уровня предприятия + UML-инструмент, поддерживающий UML 2, SysML и нотацию моделирования бизнес-процессов (BPMN) из группы управления объектами (OMG). В дополнение к поддержке моделирования он предоставляет возможности создания отчетов и разработки кода, включая генерацию. Также поддерживается  reverse engineering кода в обе стороны для различных языков программирования
7. [IBM Rational System Architect](https://www.ibm.com/support/knowledgecenter/en/SS6RBX/sa_family_welcome.html) - обеспечивает визуализацию, анализ архитектуры предприятия и обмен информацией о ней, поддерживая проводимые в организации изменения и преобразования.
