# Amazon Web Services (AWS) - список продуктов 2017

Amazon Web Services это набор облачных продуктов: вычислительные сервисы, хранилища данных, базы данных, средства аналитики, сети, мобильные технологии, инструменты для разработчиков, инструменты управления, технологии «Интернета вещей», средства обеспечения безопасности и корпоративные приложения.
